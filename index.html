sr-search-replace

Every replacement journalled, every run reversible

sr: auditable search and replace across a source tree with preview diffs, literal or regex mode, binary detection, session journals and one-command rollback. For refactors where sed -i is too blunt.

What it does

  • find, diff and replace as separate safe steps
  • Session journal with one-command rollback
  • Binary detection and backups before writing

Built with

JavaScript, Makefile, Python, Shell, TypeScript
